Proyecto: Calculadora de Presupuesto Mensual
El mantenimiento adaptativo consiste en realizar modificaciones al sistema con el fin de ajustarlo a cambios del entorno tecnológico, normativo o de usuario. Este tipo de mantenimiento es fundamental para asegurar que la Calculadora de Presupuesto Mensual continúe funcionando correctamente a pesar de las actualizaciones en sistemas, navegadores, dispositivos o requisitos externos.
A continuación, se presentan las acciones de mantenimiento adaptativo propuestas para este sistema.
________________________________________
1. Actualización por cambios tecnológicos
Compatibilidad con nuevas versiones de navegadores
A medida que Chrome, Firefox, Safari o Edge lanzan nuevas versiones, pueden dejar de soportar ciertas funciones de JavaScript o CSS utilizadas por la calculadora.
Acción:
•	Revisar periódicamente compatibilidad y actualizar funciones, estilos o librerías obsoletas.
Optimización para nuevos sistemas operativos
Nuevas versiones de Android, iOS, Windows o macOS pueden afectar la visualización o el comportamiento del sistema.
Acción:
•	Adaptar la interfaz para asegurar un funcionamiento óptimo en versiones actualizadas.
________________________________________
2. Adaptación a nuevos dispositivos y tamaños de pantalla
Uso creciente de pantallas plegables, tablets o monitores ultra-wide
La calculadora debe ajustarse al tamaño disponible sin deformar tablas, botones ni formularios.
Acción:
•	Mejorar la responsividad usando CSS Grid, Flexbox y media queries actualizadas.
 Inclusión de modo oscuro según configuración del sistema
Cada vez más usuarios prefieren interfaces que se adapten automáticamente al modo claro u oscuro del dispositivo.
Acción:
•	Integrar soporte para prefers-color-scheme en CSS.
________________________________________
3. Cambios en normativas o formatos financieros
Ajuste de formatos monetarios
Dependiendo del país, pueden cambiar formatos de moneda, separadores decimales o inflaciones que afecten el cálculo.
Acción:
•	Adaptar el formato del sistema (ej. $1,000.00 a 1.000,00 €) según región detectada automáticamente o elegida por el usuario.
 Inclusión de nuevas categorías de gastos
Los usuarios pueden requerir registrar gastos especiales según cambios financieros (inflación, nuevos servicios, suscripciones digitales, etc.).
Acción:
•	Permitir agregar nuevas categorías configurables desde la interfaz.
________________________________________
4. Adaptaciones por cambios en necesidades del usuario
 Nuevas formas de ingreso de datos
Los usuarios pueden preferir ingresar gastos mediante:
•	Voz
•	QR de tickets
•	Escaneo de factura
Acción:
•	Evaluar integración de nuevas tecnologías según demanda del usuario.
Sincronización con almacenamiento en la nube
Si los usuarios cambian dispositivos con mayor frecuencia, será necesario sincronizar datos en línea.
Acción:
•	Adaptar el sistema para guardar datos en servicios como Google Drive, Dropbox o almacenamiento propio.
________________________________________
5. Mejora de accesibilidad según estándares actualizados
Los lineamientos WCAG y otros estándares de accesibilidad evolucionan constantemente.
Acción:
•	Ajustar tamaños de fuente, colores, contraste y navegación por teclado según nuevas recomendaciones accesibles.
________________________________________
Conclusión
El mantenimiento adaptativo asegura que la Calculadora de Presupuesto Mensual siga siendo funcional, moderna y compatible con las nuevas tecnologías, dispositivos y normas.
Este tipo de mantenimiento permite que el sistema evolucione sin perder vigencia, garantizando que los usuarios puedan continuar utilizando la aplicación sin problemas en un entorno tecnológico en constante cambio.
