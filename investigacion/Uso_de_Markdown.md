# Uso de Markdown en Proyectos de Software

## 📌 1. ¿Qué es Markdown?

Markdown es un **lenguaje de marcado ligero** que permite dar formato a texto de manera sencilla usando caracteres especiales.  
Se utiliza principalmente para **documentación**, **README.md**, **notas de proyecto** y **blogs**, entre otros.

- No requiere software especial.
- Permite generar archivos **legibles en texto plano** y al mismo tiempo **con formato**.
- Se convierte fácilmente a HTML, PDF u otros formatos.

---

## 📌 2. ¿Por qué se utiliza en proyectos de software?

Markdown se usa ampliamente porque:

1. Es **simple y rápido** de escribir.
2. Permite crear **documentación clara y profesional**.
3. Se integra perfectamente con **GitHub y Git**, mostrando los archivos `.md` con formato directamente en el repositorio.
4. Facilita el **control de versiones**, ya que los cambios en texto plano son fáciles de comparar.
5. Permite combinar **texto, enlaces, tablas, imágenes y listas** en un solo archivo.
